How to use this guide

  1. Read Chapters 1–3 first. They teach the vocabulary (servers, caches, databases, queues) and the interview method that every later chapter builds on.
  2. Read each chapter top to bottom. Every chapter follows the same shape: the problem in plain English, key terms, how it works step by step, diagrams, trade-offs, then an interview walkthrough.
  3. Test yourself. Answer the quiz questions at the end of each chapter before clicking to reveal the answer. Retrieval practice is what makes things stick.
  4. Revise from the cheat sheet. Each chapter ends with a one-screen summary to review the night before an interview.
